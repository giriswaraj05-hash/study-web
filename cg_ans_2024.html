✅ Questions & Answers
Q1
DDA vs Bresenham line drawing algorithm.
Answer
DDA: calculates next pixel using Δx and Δy, uses floating point, slower. Steps: dx=x2-x1, dy=y2-y1, steps=max(|dx|,|dy|), xi=dx/steps, yi=dy/steps, plot each step. Bresenham: uses only integer arithmetic, faster. Decision parameter pk=2Δy-Δx. If pk≥0: y increments, pk=pk+2Δy-2Δx. Else pk=pk+2Δy.
Q2
Midpoint circle algorithm.
Answer
Start at (0,r). Decision parameter p=1-r. If p<0: next point (x+1,y), p=p+2x+3. If p≥0: next point (x+1,y-1), p=p+2x-2y+5. Plot all 8 symmetric points each step. Continue until x≥y. Uses integer arithmetic only — faster than trigonometric methods.
Q3
2D Transformations.
Answer
Translation: [x,y,1]×[1,0,0; 0,1,0; tx,ty,1]. Rotation by θ: [cosθ,-sinθ,0; sinθ,cosθ,0; 0,0,1]. Scaling: [sx,0,0; 0,sy,0; 0,0,1]. Homogeneous coordinates allow composite transformations by matrix multiplication.
