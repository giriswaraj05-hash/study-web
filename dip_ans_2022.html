Q1
What is image segmentation? Explain edge detection using the Sobel and Prewitt operators.
ANSWER
Image segmentation is the process of partitioning a digital image into multiple regions or sets of pixels that share common characteristics (intensity, color, texture), making it easier to analyze meaningful objects rather than the whole image.

Edge detection finds points where intensity changes sharply, using gradient-based masks:
  • Sobel operator: Uses two 3×3 kernels (Gx and Gy) that approximate the derivative in horizontal and vertical directions, with weighting that gives more importance to center pixels — this provides smoothing along with edge detection, reducing noise sensitivity.
  • Prewitt operator: Also uses two 3×3 kernels similar to Sobel, but with equal weights (no extra emphasis on center row/column) — slightly simpler but more noise-sensitive than Sobel.
The gradient magnitude is computed as √(Gx² + Gy²), and pixels with magnitude above a threshold are marked as edges.
Q2
Explain region-based segmentation techniques: region growing and region splitting and merging.
ANSWER
Region growing: Starts with one or more "seed" pixels and grows the region by appending neighboring pixels that satisfy a similarity criterion (e.g., similar intensity within a threshold). The process continues until no more pixels can be added — useful when seed points are known in advance.

Region splitting and merging: Starts by treating the whole image as one region, then:
  • Splitting: If a region does not satisfy a homogeneity criterion, it is split into four quadrants (often using a quadtree structure), and the process repeats recursively.
  • Merging: Adjacent regions that together satisfy the homogeneity criterion are merged back together.
This combined approach avoids over-segmentation and adapts well to images with regions of varying size.
Q3
What is image restoration? Explain the degradation model used in image restoration.
ANSWER
Image restoration is the process of recovering an original, clean image from a degraded (blurred/noisy) observed image by applying the inverse of the known or estimated degradation process — unlike enhancement, it uses an objective, mathematical model rather than subjective improvement.

Degradation model:
g(x,y) = h(x,y) * f(x,y) + η(x,y)
  • f(x,y) = original image
  • h(x,y) = degradation function (e.g., blur due to motion or out-of-focus lens), applied via convolution (*)
  • η(x,y) = additive noise
  • g(x,y) = observed degraded image
Restoration techniques (inverse filtering, Wiener filtering) attempt to estimate f(x,y) given g(x,y) and knowledge/estimates of h and η.
Q4
Describe the Wiener filter and its role in removing noise from a degraded image.
ANSWER
The Wiener filter is a statistical approach to image restoration that minimizes the mean square error between the estimated and the original image, accounting for both the degradation function and the noise statistically — unlike inverse filtering, it does not blow up when noise is present.

In the frequency domain, the Wiener filter is given by:
F̂(u,v) = [ H*(u,v) / (|H(u,v)|² + Sη/Sf) ] × G(u,v)

where H*(u,v) is the complex conjugate of the degradation function, and Sη/Sf is the noise-to-signal power ratio. When noise is negligible, this reduces to simple inverse filtering; when noise is high, the filter automatically suppresses noise amplification, giving a more stable and visually better restored image than direct inverse filtering.
Q5
Explain different types of noise models in image processing: Gaussian, salt-and-pepper, and Rayleigh noise.
ANSWER
  • Gaussian noise: Caused by sensor electronic noise or low lighting; its probability density function follows a bell-shaped (normal) curve. It affects every pixel slightly and is best reduced using averaging/Gaussian smoothing filters.
  • Salt-and-pepper noise: Appears as random black and white pixels scattered across the image (caused by faulty sensors or transmission errors). It is best removed using a median filter, which is highly effective against this impulsive noise.
  • Rayleigh noise: Common in range imaging; its PDF is skewed (non-symmetric) and is typically modeled with a characteristic function used in radar and ultrasound image restoration.
Choosing the right denoising filter depends on correctly identifying which noise model best matches the observed image's histogram shape.
Q6
What is thresholding? Explain global and adaptive (local) thresholding with examples.
ANSWER
Thresholding is a simple segmentation technique that converts a grayscale image into a binary image by classifying each pixel as foreground or background based on its intensity value compared to a threshold T.

Global thresholding: A single threshold value T is applied to the entire image: g(x,y) = 1 if f(x,y) > T, else 0. Works well when the image has uniform lighting and a clear bimodal histogram (e.g., scanned printed text on a clean white background).

Adaptive (local) thresholding: The threshold value varies across the image, computed separately for different regions/windows. This is necessary when illumination is uneven across the image (e.g., a photograph of a document with shadows), since a single global threshold would misclassify pixels in darker areas.
