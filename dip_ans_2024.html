Q1
What is morphological image processing? Explain dilation and erosion with examples.
ANSWER
Morphological image processing is a set of techniques for analyzing and processing the shape and structure of objects in an image, typically applied to binary images, using a small shape called a "structuring element" (kernel) that is moved across the image.

Dilation: Expands/grows the boundaries of foreground objects. A pixel is set to foreground if the structuring element overlaps with at least one foreground pixel of the image at that position. It is used to fill small holes and connect nearby objects.

Erosion: Shrinks the boundaries of foreground objects. A pixel remains foreground only if the structuring element is fully contained within the foreground region. It is used to remove small noise specks and thin object boundaries.

Example: Eroding a binary image of handwriting removes thin noise dots, while dilation can be used afterward to restore the original stroke thickness of the letters.
Q2
Explain the opening and closing operations in morphology and their applications.
ANSWER
Opening = Erosion followed by Dilation (using the same structuring element).
  • Removes small objects/noise while preserving the size and shape of larger objects.
  • Smooths object contours by removing small protrusions.
  • Application: removing small dots/noise from a scanned binary image without shrinking the main objects.
Closing = Dilation followed by Erosion.
  • Fills small holes and gaps inside objects, and smooths concave boundary notches.
  • Connects nearby objects that are close together.
  • Application: filling small gaps inside a scanned character or connecting broken parts of a printed line.
Both operations are "idempotent" — applying them repeatedly after the first pass produces no further change.
Q3
Describe the RGB, HSI and YCbCr color models used in color image processing.
ANSWER
  • RGB model: Represents color as a combination of Red, Green, and Blue intensities, forming a cube where each axis ranges 0–255. It is hardware-oriented (used by cameras, displays) but not intuitive for human perception-based editing.
  • HSI model (Hue, Saturation, Intensity): Separates color information (hue = actual color, saturation = purity/vividness) from brightness (intensity). This matches how humans naturally describe colors, making it ideal for tasks like color-based segmentation.
  • YCbCr model: Separates luminance (Y) from chrominance (Cb = blue difference, Cr = red difference). It is widely used in image/video compression (like JPEG, MPEG) because the human eye is less sensitive to chrominance detail, allowing chrominance channels to be compressed more aggressively than luminance.
Q4
What is pseudo color image processing? Explain intensity slicing with an example.
ANSWER
Pseudo color (false color) image processing assigns colors to a grayscale image based on a specified mapping, not because the object actually has that color, but to make certain features easier for the human eye to interpret and distinguish.

Intensity slicing: The simplest pseudo-coloring technique — the gray-level range (0 to L−1) is divided into a number of intervals, and a distinct color is assigned to each interval.

Example: In a satellite weather image, temperature data represented in grayscale can be sliced and color-coded — e.g., assigning blue to cold zones, yellow to moderate zones, and red to hot zones — making it instantly easier for viewers to identify storm intensity regions instead of reading subtle gray-level differences.
Q5
Explain boundary extraction and skeletonization as morphological algorithms.
ANSWER
Boundary extraction: Obtains the outer boundary of an object by subtracting its eroded version from the original: β(A) = A − (A ⊖ B), where B is the structuring element. This isolates only the outermost layer of foreground pixels, giving a thin outline of the object.

Skeletonization (thinning): Reduces an object to its skeletal, single-pixel-wide representation while preserving its overall shape and connectivity. It is computed by iteratively applying morphological thinning, identifying the "medial axis" — points equidistant from the object's boundaries.

Both are widely used in applications like fingerprint analysis, character/shape recognition, and extracting structural features for object matching.
Q6
What is hit-or-miss transformation? Explain its role in shape detection.
ANSWER
The Hit-or-Miss transform is a morphological operation used to detect specific shapes or patterns within a binary image, using a pair of disjoint structuring elements: B1 (must "hit" — match foreground pixels) and B2 (must "miss" — match background pixels) in the surrounding area.

A pixel location is marked as a match (output = 1) only if the foreground pattern matches B1 exactly AND the surrounding background matches B2 exactly at that location.

Role in shape detection: It is used to locate exact configurations — such as detecting specific corner shapes, isolated points, or particular junction patterns in a binary image — making it a precise tool for template-based shape matching within morphology.
