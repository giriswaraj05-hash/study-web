Q1
Explain spatial filtering. Differentiate between smoothing (low-pass) and sharpening (high-pass) spatial filters.
ANSWER
Spatial filtering is a technique where a small matrix called a "mask" or "kernel" is moved across every pixel of the image, and the output pixel value is computed as a function (usually weighted sum) of the pixel's neighborhood values under the mask.

Smoothing (low-pass) filters:
  • Blur the image by averaging neighboring pixel values, reducing sharp intensity transitions.
  • Used for noise reduction; examples: mean filter, Gaussian filter, median filter.
Sharpening (high-pass) filters:
  • Highlight fine details and edges by emphasizing intensity differences between neighboring pixels.
  • Used to enhance edges and details; examples: Laplacian filter, high-boost filter.
Smoothing reduces noise but blurs edges, while sharpening enhances edges but can amplify noise — so they are often used carefully in combination.
Q2
What is the Laplacian operator? Explain image sharpening using the Laplacian filter.
ANSWER
The Laplacian is a second-order derivative operator that measures the rate of change of intensity in all directions, making it highly sensitive to fine detail, edges, and noise. For a 2-D function f(x,y), it is defined as:

∇²f = [f(x+1,y) + f(x−1,y) + f(x,y+1) + f(x,y−1)] − 4f(x,y)

This is implemented as a 3×3 convolution mask (e.g., center value −4 or −8, surrounded by 1's).

Image sharpening using Laplacian: Since the Laplacian highlights edges, the sharpened image is obtained by subtracting the Laplacian result from the original image:
g(x,y) = f(x,y) − ∇²f(x,y)  (if mask center is negative)
This enhances fine detail and edges while keeping the overall image structure intact, commonly used in medical and satellite image enhancement.
Q3
Explain the median filter and its effectiveness in removing salt-and-pepper noise.
ANSWER
The median filter is a non-linear spatial filter that replaces each pixel's value with the median (middle value when sorted) of the intensity values in its neighborhood (e.g., a 3×3 window), instead of using an average.

Effectiveness against salt-and-pepper noise: Salt-and-pepper noise introduces extreme outlier pixel values (very bright "salt" or very dark "pepper" pixels) scattered randomly in the image. Since the median is robust to outliers (an extreme value just becomes the highest/lowest in the sorted list, but does not affect the middle value), the median filter effectively removes such impulsive noise while preserving edges much better than a mean (averaging) filter, which would instead blur the entire neighborhood including legitimate edges.
Q4
What is unsharp masking and high-boost filtering? Explain with formulas.
ANSWER
Unsharp masking: A sharpening technique where a blurred (smoothed) version of the image is subtracted from the original to obtain a "mask" containing edge/detail information, which is then added back to the original:

fs(x,y) = f(x,y) + k × [f(x,y) − f̄(x,y)]
where f̄(x,y) is the blurred version, and k = 1 for standard unsharp masking.

High-boost filtering: A generalization of unsharp masking where k > 1, amplifying the high-frequency (edge) component more strongly:

fhb(x,y) = A·f(x,y) − f̄(x,y), where A ≥ 1

A larger A value preserves more of the low-frequency content along with strongly emphasized edges, giving a sharper-looking result than standard sharpening alone.
Q5
Describe the basic relationships between pixels: neighbors, connectivity, and adjacency.
ANSWER
Neighbors:
  • 4-neighbors (N4): The 4 pixels directly above, below, left, and right of a pixel.
  • Diagonal neighbors (ND): The 4 diagonal pixels.
  • 8-neighbors (N8): Union of N4 and ND — all 8 surrounding pixels.
Adjacency: Two pixels are adjacent if they are neighbors and satisfy a similarity criterion (usually same intensity/gray-level set V):
  • 4-adjacency: Pixels are adjacent if they are in N4 and have values in V.
  • 8-adjacency: Pixels are adjacent if they are in N8 and have values in V.
  • m-adjacency (mixed): Resolves ambiguities that arise in 8-adjacency by combining rules from 4- and diagonal-adjacency.
Connectivity: A path of adjacent pixels (all satisfying V) connecting two pixels establishes that they belong to the same connected region — this concept underlies segmentation and labeling of distinct objects in an image.
Q6
Explain gray level slicing and bit-plane slicing as image enhancement techniques.
ANSWER
Gray-level slicing: Highlights a specific range of gray levels in an image while suppressing all others, either by setting the chosen range to a high value and everything else to 0 (binary slicing), or by displaying the chosen range with enhanced values while keeping the rest unchanged. Useful for highlighting specific features such as defects in an X-ray.

Bit-plane slicing: An 8-bit grayscale image can be decomposed into 8 separate binary "bit planes" (from the most significant bit, MSB, to the least significant bit, LSB). The MSB plane carries most of the visually significant information, while lower-order bit planes contribute finer detail/noise. This technique is useful for image compression (only transmitting higher-order planes) and for analyzing the relative importance of different bit levels in image data.
