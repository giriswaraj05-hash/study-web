Q1
What is object recognition in image processing? Explain pattern and pattern classes with examples.
ANSWER
Object recognition is the final stage of an image processing pipeline, where labels (e.g., "circle", "letter A", "tumor") are assigned to segmented objects based on extracted descriptors, typically by comparing them against known reference patterns.

Pattern: An arrangement of descriptors (features) — such as a feature vector of measurements (area, perimeter, texture values) — that represents an object.

Pattern class: A family/category of patterns that share common properties, denoted as ω1, ω2, ..., ωW.

Example: In handwritten digit recognition, each digit (0–9) forms a separate pattern class. A new handwritten sample is converted into a feature vector (its "pattern") and classified into the pattern class (digit) whose reference patterns it most closely matches.
Q2
Explain the boundary descriptors: chain codes and shape numbers, used in object representation.
ANSWER
Chain codes: Represent an object's boundary as a sequence of directional moves (typically 4-directional or 8-directional) from one boundary pixel to the next, where each direction is assigned a numeric code (e.g., 0=right, 1=up-right, 2=up, etc. for 8-direction code). This gives a compact, sequential representation of the shape's outline.

Shape numbers: Derived from the chain code by first computing the "first difference" of the chain code (the number of direction changes between consecutive code elements), then finding the rotation of this difference sequence that gives the minimum integer value. This makes the shape number invariant to the starting point on the boundary and to rotation (in multiples of the basic direction angle), making it useful for comparing and matching object shapes regardless of orientation.
Q3
What is the wavelet transform? Explain its advantages over the Fourier transform for image analysis.
ANSWER
The wavelet transform decomposes an image into components at multiple scales (resolutions) using small wave-like functions called "wavelets" that are localized in both space and frequency, unlike the sine/cosine basis functions of the Fourier transform which extend infinitely.

Advantages over Fourier transform:
  • Joint space-frequency localization: Wavelets capture both "where" (spatial location) and "what frequency" a feature occurs at, while Fourier transform only reveals global frequency content without spatial location.
  • Multiresolution analysis: Wavelets naturally support analyzing an image at different resolutions simultaneously (coarse to fine), which is ideal for tasks like progressive image transmission and compression (e.g., JPEG2000).
  • Better handling of non-stationary signals: Real images have features (edges, textures) that vary locally — wavelets adapt to this, whereas Fourier assumes global periodicity.
Q4
Describe regional descriptors: area, perimeter, and texture, used in image feature extraction.
ANSWER
Regional descriptors quantify properties of an entire object region (not just its boundary), useful for distinguishing and classifying objects.
  • Area: The total number of pixels contained within the region — a simple but useful measure of object size.
  • Perimeter: The length of the region's boundary (total number of boundary pixels, or computed via chain-code direction lengths) — used along with area to compute shape measures like compactness (perimeter² / area).
  • Texture: Describes the surface properties of a region — smoothness, coarseness, and regularity of intensity patterns. Common texture measures include statistical methods (using the gray-level co-occurrence matrix, GLCM, to compute contrast, correlation, energy) and structural/spectral methods that analyze repeating patterns.
Together, these descriptors form feature vectors used in classification and recognition tasks.
Q5
Explain the minimum distance classifier for statistical pattern recognition.
ANSWER
The minimum distance classifier is a simple statistical pattern recognition method that assigns an unknown pattern to the class whose "mean vector" (prototype) is closest to it, using a distance measure (commonly Euclidean distance).

Working:
  • For each known class ωj, compute the mean feature vector mj from training samples.
  • For an unknown pattern x, compute the distance Dj(x) = ||x − mj|| for every class.
  • Assign x to the class with the smallest distance Dj(x).
This classifier works well when pattern classes form well-separated, compact clusters in feature space, but performs poorly when classes overlap significantly or have very different variances — in which case more advanced classifiers (Bayes classifier) are preferred.
Q6
What is the Hough transform? Explain its use in detecting lines and shapes in an image.
ANSWER
The Hough transform is a feature extraction technique used to detect simple shapes (lines, circles) in an image, even when the shape is broken, noisy, or partially obscured, by transforming points in image space into a "parameter space."

For line detection: Every edge point (x,y) in the image votes for all possible lines (ρ, θ) that could pass through it, using the equation ρ = x·cosθ + y·sinθ. These votes accumulate in a 2-D accumulator array (Hough space); peaks in this accumulator correspond to lines that are strongly present across many edge points in the original image.

This robust voting-based mechanism allows the Hough transform to detect lines (and similarly circles, using a 3-parameter version) reliably even in the presence of gaps and noise — making it widely used for tasks like lane detection in road images.
