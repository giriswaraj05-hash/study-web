Q1
What is digital image processing? Explain the fundamental steps involved in image processing with a block diagram.
ANSWER
Digital Image Processing (DIP) is the use of a digital computer to process digital images through an algorithm. It converts an image into digital form (a matrix of pixel values) and applies operations on it to enhance, analyze, or extract useful information.
  • Image acquisition — capturing the image using a sensor/camera and digitizing it.
  • Image enhancement — improving visual appearance (contrast, brightness).
  • Image restoration — removing degradation/noise using mathematical models.
  • Color image processing — handling color models like RGB, HSI.
  • Wavelets/multiresolution — processing image at different resolutions.
  • Compression — reducing storage/transmission size (JPEG, etc.).
  • Morphological processing — extracting shape-based image components.
  • Segmentation — partitioning image into meaningful regions/objects.
  • Representation & description — converting segmented data into a usable form.
  • Object recognition — assigning labels to objects based on descriptors.
These steps form a continuous pipeline, with a knowledge base supporting each stage.
Q2
Explain the image formation model. Derive the relation between brightness, illumination and reflectance.
ANSWER
An image is formed when light from a source falls on an object and is reflected toward a sensor. This is modeled mathematically as:

f(x, y) = i(x, y) × r(x, y)

where:
  • i(x, y) = illumination component — the amount of light falling on the scene (determined by the light source).
  • r(x, y) = reflectance component — the fraction of light reflected by the object's surface (0 to 1), determined by the object's properties.
  • f(x, y) = resulting image intensity (brightness) at point (x, y).
Illumination depends on the light source and can range from very low (night) to very high (sunlight), while reflectance depends on the object material (e.g., black velvet ≈ 0.01, snow ≈ 0.93). This model is the foundation for techniques like homomorphic filtering, which separately processes the illumination and reflectance components to enhance images taken under poor lighting.
Q3
What is histogram equalization? Explain its working with a suitable example.
ANSWER
Histogram equalization is a contrast enhancement technique that redistributes the intensity values of an image so that the output histogram is approximately uniform, making dark/low-contrast images clearer.

Working:
  • Compute the histogram (frequency of each gray level) of the input image.
  • Compute the normalized cumulative distribution function (CDF) of the gray levels.
  • Map each input gray level to a new gray level using the transformation: s = T(r) = (L−1) × CDF(r), where L is the number of gray levels.
  • Replace original pixel values with the new mapped values.
Example: A dark, low-contrast X-ray image where most pixels are clustered in a narrow range (say 20–60) will, after equalization, have its pixel values spread across the full 0–255 range, making bone structures and soft tissue much more distinguishable.
Q4
Differentiate between spatial domain and frequency domain image enhancement techniques.
ANSWER
Spatial Domain:
  • Operates directly on pixel values of the image: g(x,y) = T[f(x,y)].
  • Includes point processing (negation, log transform) and mask/filter-based processing (smoothing, sharpening).
  • Computationally simpler and faster for small kernels.
  • Examples: histogram equalization, median filtering, Laplacian sharpening.
Frequency Domain:
  • Image is first transformed using Fourier Transform into the frequency domain.
  • Filters (low-pass, high-pass, band-pass) are applied to the frequency components.
  • Inverse Fourier Transform converts the result back to the spatial domain.
  • Better suited for periodic noise removal and global frequency-based analysis.
  • Examples: ideal/Butterworth/Gaussian low-pass and high-pass filtering.
Q5
Explain the working of an ideal low-pass filter and a Butterworth low-pass filter in frequency domain.
ANSWER
Ideal Low-Pass Filter (ILPF): Passes all frequencies within a circle of radius D₀ from the origin (center of frequency spectrum) and completely blocks all frequencies outside it.
H(u,v) = 1 if D(u,v) ≤ D₀, else 0.
Because of its sharp cutoff, it causes noticeable ringing artifacts (Gibbs phenomenon) in the output image.

Butterworth Low-Pass Filter (BLPF): Provides a smooth transition between passed and blocked frequencies, controlled by an order parameter n.
H(u,v) = 1 / [1 + (D(u,v)/D₀)2n]
A higher order n makes it behave more like an ideal filter (sharper cutoff), while a lower n gives a smoother transition with minimal ringing — making BLPF generally preferred over ILPF for practical smoothing.
Q6
What is image sampling and quantization? Explain their effect on image quality.
ANSWER
Sampling: The process of digitizing the spatial coordinates of an image — converting a continuous image into a discrete grid of pixels. The number of samples determines the image's spatial resolution.

Quantization: The process of digitizing the amplitude (intensity) values at each sampled point into discrete gray levels. The number of quantization levels determines the gray-level resolution.

Effect on quality:
  • Low sampling rate → fewer pixels → blocky/pixelated image, loss of fine detail (checkerboard effect).
  • Low quantization levels → fewer gray shades → visible false contours / banding in smooth gradient regions.
  • Higher sampling and quantization improve image quality but increase storage and processing cost — so a trade-off is chosen based on application needs.
