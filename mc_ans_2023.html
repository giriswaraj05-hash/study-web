✅ Questions & Answers
Q1
What is mobile computing? Explain characteristics and challenges.
Answer
Mobile computing allows users to access data and services wirelessly while moving. Characteristics: portability, connectivity, interactivity, individuality. Challenges: limited bandwidth, battery life, security vulnerabilities, heterogeneous networks, limited processing power.
Q2
Explain GSM architecture.
Answer
GSM has 3 parts: BSS (Base Station Subsystem) – BTS (transmits/receives) + BSC (controls BTS). NSS (Network Switching Subsystem) – MSC, HLR, VLR, AuC, EIR. OSS (Operation Support System) – network management. MS (Mobile Station) – handset + SIM.
Q3
What is handoff? Types?
Answer
Handoff transfers active call from one cell to another. Hard Handoff: breaks old connection before new one (break-before-make). Soft Handoff: maintains both connections simultaneously (CDMA). Horizontal: same network. Vertical: different network types (WiFi to 4G).
