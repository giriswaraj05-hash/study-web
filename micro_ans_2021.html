✅ Questions & Answers
Q1
What is a microprocessor? Explain the internal architecture of 8085.
Answer
A microprocessor is a programmable digital device that performs arithmetic, logic, and control operations. The 8085 architecture includes: ALU (performs arithmetic/logic), Registers (A, B, C, D, E, H, L, SP, PC), Control Unit (manages operations), and three buses — 8-bit data bus, 16-bit address bus, and control bus.
Q2
Describe the fetch-decode-execute cycle.
Answer
Fetch: PC sends address to memory, instruction is copied to IR. Decode: Control unit decodes the opcode. Execute: ALU or registers perform the required operation. PC is incremented after each fetch.
Q3
Write an 8085 program to add two 8-bit numbers.
Answer
MVI A, 25H — Load first number into A
MVI B, 15H — Load second number into B
ADD B — Add B to A, result in A
STA 3000H — Store result in memory
HLT — Stop
Q4
Explain the types of interrupts in 8085.
Answer
Non-Maskable: TRAP — highest priority, cannot be disabled. Maskable (can be enabled/disabled with EI/DI): RST 7.5 (edge triggered), RST 6.5 (level triggered), RST 5.5 (level triggered), INTR (lowest priority, vectored by external device).
Q5
What is memory interfacing? Explain RAM interfacing.
Answer
Memory interfacing connects memory chips to the microprocessor using address, data, and control buses. For RAM interfacing with 8085: address lines A0-A12 connect to RAM, data lines D0-D7 are bidirectional, WR and RD signals control read/write, CE (chip enable) is derived using address decoding logic.
Q6
Differentiate between RISC and CISC.
Answer
RISC: Simple instructions, fixed length, fewer addressing modes, more registers, fast execution (1 clock cycle). Example: ARM. CISC: Complex instructions, variable length, many addressing modes, fewer registers, multi-cycle execution. Example: 8086, Pentium.
