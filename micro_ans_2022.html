✅ Questions & Answers
Q1
Explain the pin diagram of 8085 microprocessor.
Answer
8085 has 40 pins: AD0-AD7 (multiplexed address/data bus), A8-A15 (upper address), ALE (Address Latch Enable), RD, WR (read/write control), IO/M (I/O or memory select), RESET IN/OUT, CLK, INTR, RST 5.5/6.5/7.5, TRAP, SID, SOD, Vcc (+5V), Vss (GND).
Q2
What are addressing modes? Explain all modes.
Answer
Register: operand in register. Example: MOV A,B. Immediate: operand in instruction. Example: MVI A,05H. Direct: operand address in instruction. Example: LDA 2050H. Indirect: address stored in register pair. Example: MOV A,M (M=HL pair). Implicit: operand implied. Example: CMA.
Q3
Write an 8085 program for Bubble Sort.
Answer
LXI H, 2000H — point to array
MVI C, 04H — count-1 passes
OUTER: MVI B, 04H — inner count
INNER: MOV A, M — load element
INX H — next element
CMP M — compare
JC SKIP — if A less, skip
MOV D,M / MOV M,A / DCX H / MOV M,D / INX H — swap
SKIP: DCR B / JNZ INNER
DCR C / JNZ OUTER / HLT
Q4
Describe 8255 PPI and its modes.
Answer
8255 has 3 ports (A, B, C) and a control register. Mode 0: Simple I/O, any port input or output. Mode 1: Strobed I/O, handshaking with Port A or B. Mode 2: Bidirectional bus I/O, only Port A. Control word decides port direction and mode.
Q5
Explain 8086 architecture and compare with 8085.
Answer
8086: 16-bit processor, 20-bit address bus (1MB memory), divided into BIU and EU, has pipelining. 8085: 8-bit processor, 16-bit address (64KB memory), no pipelining, simpler. 8086 is faster, supports segmentation, more registers, more instructions.
Q6
What is DMA? Explain 8257.
Answer
DMA (Direct Memory Access) allows data transfer between memory and I/O without CPU. 8257 is a 4-channel DMA controller. It has DMA Request (DRQ), DMA Acknowledge (DACK), address registers, count registers. CPU grants bus control to 8257 via HOLD/HLDA signals.
