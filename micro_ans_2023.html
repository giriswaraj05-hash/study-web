✅ Questions & Answers
Q1
Explain register organization of 8085.
Answer
8085 has: Accumulator (A) — 8-bit, main arithmetic register. General purpose: B, C, D, E, H, L — can pair as BC, DE, HL for 16-bit ops. SP (Stack Pointer) — 16-bit, points to top of stack. PC (Program Counter) — 16-bit, holds next instruction address. Flag register — 8-bit: S, Z, AC, P, CY flags.
Q2
What is ISR? Explain TRAP and RST interrupts.
Answer
ISR (Interrupt Service Routine) is the program executed when an interrupt occurs. TRAP: Non-maskable, highest priority, edge and level triggered, jumps to 0024H. RST 7.5: edge triggered, maskable, jumps to 003CH. RST 6.5: level triggered, jumps to 0034H. RST 5.5: level triggered, jumps to 002CH.
Q3
Write 8085 program to multiply two 8-bit numbers.
Answer
MVI B, 05H — multiplier
MVI C, 04H — multiplicand
MVI A, 00H — clear accumulator
LOOP: ADD C — add C to A
DCR B — decrement B
JNZ LOOP — repeat until B=0
STA 3000H — store result

Q4
Describe PUSH and POP stack operations.
Answer
Stack: LIFO memory area. SP points to top. PUSH rp: SP decremented by 2, register pair stored. Example: PUSH BC stores B at SP-1, C at SP-2. POP rp: register pair loaded from stack, SP incremented by 2. Used for saving registers during subroutine calls.
Q5
Explain memory segmentation in 8086.
Answer
8086 divides 1MB memory into segments of 64KB each. CS (Code Segment): holds program code. DS (Data Segment): holds data. SS (Stack Segment): holds stack. ES (Extra Segment): extra data. Physical address = Segment × 10H + Offset.
Q6
What is ADC interfacing? Explain with circuit.
Answer
ADC (Analog to Digital Converter) converts analog signals to digital. ADC0804 is commonly interfaced with 8085. Steps: Send START pulse, wait for EOC (End of Conversion), read digital output via data bus. Used in temperature sensors, voltmeters.
