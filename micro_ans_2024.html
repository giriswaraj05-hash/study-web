✅ Questions & Answers
Q1
Describe data bus, address bus and control bus of 8085.
Answer
Data Bus: 8-bit bidirectional (AD0-AD7), multiplexed with lower address. Carries data between CPU and memory/IO. Address Bus: 16-bit unidirectional (A8-A15 + demultiplexed AD0-AD7). Selects memory location (64KB range). Control Bus: RD, WR, ALE, IO/M, S0, S1 — controls direction and type of data transfer.
Q2
Explain BIU and EU in 8086.
Answer
BIU (Bus Interface Unit): Fetches instructions from memory, manages segment registers (CS,DS,SS,ES), IP, 6-byte instruction queue (pipeline). EU (Execution Unit): Decodes and executes instructions, contains ALU, general purpose registers (AX,BX,CX,DX), flag register. BIU and EU work simultaneously for faster execution.
Q3
Write 8085 program to find largest number in array.
Answer
LXI H, 2000H — array start
MVI C, 05H — count
MOV A, M — first element in A
LOOP: INX H — next element
CMP M — compare A with M
JNC SKIP — if A >= M, skip
MOV A, M — else update max
SKIP: DCR C / JNZ LOOP
STA 3010H — store max

Q4
Explain minimum and maximum mode of 8086.
Answer
Minimum Mode (MN/MX=1): 8086 generates all control signals itself. Used in single processor systems. Simple and less costly. Maximum Mode (MN/MX=0): Control signals generated by 8288 Bus Controller. Used in multiprocessor systems. Supports coprocessors like 8087, 8089.
Q5
What is 8253/8254 Programmable Interval Timer?
Answer
8253/8254 has 3 independent 16-bit counters. Each counter has CLK, GATE, OUT pins. 6 modes: Mode 0 (interrupt on terminal count), Mode 1 (hardware retriggerable), Mode 2 (rate generator), Mode 3 (square wave), Mode 4 (software triggered), Mode 5 (hardware triggered). Used for timing, baud rate generation.
Q6
Differentiate microprocessor and microcontroller.
Answer
Microprocessor: CPU only, needs external RAM/ROM/IO, general purpose, high speed, costly. Example: 8085, 8086. Microcontroller: CPU + RAM + ROM + IO on one chip, special purpose, low power, cheap. Example: 8051, Arduino. Microcontrollers used in embedded systems.
