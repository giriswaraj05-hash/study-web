✅ Questions & Answers
Q1
Explain evolution of microprocessors 4-bit to 64-bit.
Answer
4-bit: Intel 4004 (1971) — first microprocessor, 2300 transistors. 8-bit: Intel 8085 (1976) — 64KB memory. 16-bit: Intel 8086 (1978) — 1MB memory, pipelining. 32-bit: 80386 (1985) — 4GB memory, virtual memory. 64-bit: Pentium 4, Core i series — multi-core, GHz speed, billions of transistors.
Q2
Write 8085 program for BCD addition.
Answer
MVI A, 47H — first BCD number (47)
MVI B, 25H — second BCD number (25)
ADD B — binary addition → A = 6CH
DAA — Decimal Adjust Accumulator → A = 72H (correct BCD result)
STA 3000H — store result
HLT
DAA adjusts result to valid BCD after addition.
Q3
What is 7-segment display interfacing?
Answer
7-segment display has segments a-g. Each digit needs a 7-bit pattern. 8085 sends data via 8255 Port A. For digit "0": pattern = 3FH. Lookup table stores all patterns 0-9. Program fetches pattern, sends to display. Multiple digits use multiplexing — enable one digit at a time rapidly.
Q4
Describe hardware and software interrupts of 8085.
Answer
Hardware: TRAP (0024H, non-maskable), RST7.5 (003CH), RST6.5 (0034H), RST5.5 (002CH), INTR (user-defined vector). Software: RST0 (0000H), RST1 (0008H)... RST7 (0038H) — called by instruction in program. SIM instruction sets masks for RST5.5/6.5/7.5. RIM reads interrupt status.
Q5
Explain instruction set classification of 8085.
Answer
Data Transfer: MOV, MVI, LDA, STA, LHLD, SHLD. Arithmetic: ADD, SUB, INR, DCR, DAD. Logical: ANA, ORA, XRA, CMA, RLC, RRC. Branch: JMP, JC, JZ, JNZ, CALL, RET. Machine Control: HLT, NOP, EI, DI, SIM, RIM. Total ~246 instructions.
Q6
What are the features of Pentium processor?
Answer
64-bit data bus, 32-bit address bus (4GB). Superscalar — 2 pipelines (U and V) execute 2 instructions simultaneously. On-chip 8KB code cache + 8KB data cache. Built-in FPU (Floating Point Unit). 3.1 million transistors. Clock: 60-200MHz. Supports MMX, SSE in later versions.
