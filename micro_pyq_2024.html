📋 Group A — Q1 (2×10=20)
Choose the correct answer from the given alternatives and explain your answer (any ten). 1 mark for right answer + 1 mark for correct explanation. Answer any Five (05) Questions from Group B.
i
Which of the following is true about microprocessors?
(a) It has an internal memory   (b) It has interfacing circuits   (c) It contains ALU, CU, and registers   (d) It uses Harvard architecture
ii
The correct sequence of operations in a microprocessor is -
(a) Opcode fetch, memory read, memory write, I/O read, I/O write   (b) Opcode fetch, memory write, memory read, I/O read, I/O write   (c) I/O read, opcode fetch, memory read, memory write, I/O write   (d) I/O read, opcode fetch, memory read, I/O write, memory read, I/O write
iii
Which of the following is NOT a microprocessor?
(a) 4004   (b) 8008   (c) 8085   (d) 8051
iv
Conditional instructions are independent of _____ flag.
(a) Z   (b) AC   (c) CY   (d) P
v
8086 is a _____ pin IC.
(a) 14   (b) 28   (c) 32   (d) 40
vi
NMI pin stands for -
(a) Neo-Makeable Interrupt   (b) Non-Makeable Interrupt   (c) Neo-Makeable Instruction   (d) Non-Makeable Instruction
vii
80286 consist of about _____ numbers of transistors.
(a) 134000   (b) 100000   (c) 10000   (d) 13400
viii
The pin that clears the control word register of 8255 when enabled is -
(a) CLEAR   (b) SET   (c) RESET   (d) CLK
ix
Port C of 8255 can function independently as -
(a) input port   (b) output port   (c) either input or output ports   (d) both input and output ports
x
The register that can be used as a scratch pad is -
(a) Accumulator   (b) B register   (c) Data register   (d) Accumulator and B register
xi
8051 microcontroller consists of -
(a) 4 latches   (b) 2 timer registers   (c) 4 on-chip I/O ports   (d) all of the mentioned
xii
In 8051 microcontroller the registers that are not accessible by the user are -
(a) Accumulator and B register   (b) IP and IE   (c) Instruction registers   (d) TMP1 and TMP2
xiii
In 8051 microcontroller ALP the instruction, ADD A, #100 performs -
(a) 100(decimal) is added to contents of address register   (b) 100(hexadecimal) is added to the accumulator   (c) 100(decimal) is added to contents of an accumulator   (d) 100(hexadecimal) is added to contents of address register
xiv
8051 microcontroller has _____ Special Function Registers.
(a) 8   (b) 11   (c) 16   (d) 21
xv
8051 microcontroller can access upto _____ KB of program memory & _____ KB of external data memory.
(a) 64 & 64   (b) 64 & 32   (c) 32 & 64   (d) 32 & 32
